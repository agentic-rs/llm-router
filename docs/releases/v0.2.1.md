# tokn v0.2.1

Historical release notes for commit `27b1098de90d231c60a39169ac0abbf3689ae2a8`
(`chore: prepare v0.2.1 release`). This release precedes the v2 gateway work.

## Highlights

- Embedded Rust and Python SDKs, friendly generation APIs, provider-aware
  generation controls, and initial TypeScript bindings.
- API-key provider access restrictions and request attribution.
- Configurable API CORS policy and automatic refresh of cached proxy leaf
  certificates before expiry.
- Session persistence based on message trees, including streamed-prefix
  preservation and improved session inspection and usage views.
- Better Codex request correlation, web-search rendering, and request overview.
- Provider-aware OpenCode linking.
- Release preparation improves model-catalogue build reproducibility and keeps
  Python binding requirements separate from ordinary Rust builds.

These notes describe the historical source snapshot, not new registry publication.
